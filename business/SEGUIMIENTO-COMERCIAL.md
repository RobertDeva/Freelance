# Seguimiento comercial — Robe Digital Studio

## Columnas para una hoja de cálculo

Crear una hoja con estas columnas:

| Campo | Uso |
|---|---|
| Fecha de investigación | Cuándo se revisó el negocio |
| Negocio | Nombre comercial |
| Nicho | Taller, salón, cafetería u otro |
| Sitio web público | URL si existe |
| Problema observable | Un problema concreto, sin suposiciones no verificadas |
| Contacto público | Canal profesional publicado por el negocio |
| Fecha del primer mensaje | Para evitar duplicados |
| Estado | Pendiente, contactado, respondió, reunión, propuesta, ganado, perdido |
| Próxima acción | Acción concreta y respetuosa |
| Fecha de seguimiento | Fecha para revisar |
| Oferta relevante | Web esencial o agenda/seguimiento |
| Valor propuesto | Importe de la propuesta, no ingreso cobrado |
| Resultado | Resumen breve |
| Permiso para caso de estudio | Sí/no |

Guardar solo los datos necesarios para la gestión comercial y respetar la normativa aplicable de privacidad y comunicaciones.

## Rutina de 45–60 minutos por día laborable

1. **10 minutos:** identificar negocios que encajen con una oferta.
2. **20 minutos:** enviar hasta cinco mensajes personalizados.
3. **10 minutos:** responder a conversaciones existentes.
4. **10 minutos:** actualizar la hoja de seguimiento.
5. **5–10 minutos:** mejorar una demo o propuesta a partir de objeciones reales.

Si la calidad baja, reducir el volumen. No enviar mensajes masivos, no automatizar spam y no continuar si alguien pide que no se le contacte.

## Revisión semanal

Responder:
- ¿Qué nicho respondió más?
- ¿Qué problema apareció repetidamente?
- ¿Qué mensaje generó conversaciones?
- ¿Cuántas conversaciones llegaron a propuesta?
- ¿Por qué se perdieron las oportunidades?
- ¿Cuánto tiempo tomaría entregar la oferta?
- ¿Qué parte podría convertirse en plantilla?
- ¿Qué gasto o dependencia de terceros podría evitarse?

## Criterios para cambiar de estrategia

- Si después de 30 contactos bien seleccionados no hay respuestas, revisar la personalización, la propuesta y el nicho.
- Si hay respuestas pero no reuniones, hacer más clara la utilidad de la demo.
- Si hay reuniones pero no propuestas aceptadas, revisar alcance, confianza, precio y forma de explicar el resultado.
- Si se vende pero el proyecto consume demasiadas horas, reducir alcance o mejorar el proceso antes de vender más.
