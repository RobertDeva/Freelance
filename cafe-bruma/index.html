Una mesa para todos

Un lugar que se siente cercano.

Café Bruma nació de una idea sencilla: crear un lugar amable donde el primer café del día, una conversación larga o una hora de trabajo se sientan igual de bienvenidos.

Trabajamos con café de origen, horneamos en pequeñas tandas y procuramos que cada visita tenga su propio ritmo. Este sitio es un prototipo de portafolio para una cafetería ficticia.
